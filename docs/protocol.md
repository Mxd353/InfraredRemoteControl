# NEC 红外协议说明

## 概述

NEC 协议使用 **38kHz 载波** 进行红外信号调制，是空调、电视、机顶盒等家电遥控器中最常见的协议之一。

## 电气特性

- **载波频率**：38kHz（占空比约 1/3 或 1/2）
- **调制方式**：脉宽调制（Pulse Distance）
    - 载波开启 = 逻辑 1（LED 闪烁）
    - 载波关闭 = 逻辑 0（LED 熄灭）

## NEC 单帧结构

```
┌──────────────────────────────────────────────────────┐
│  Leader     │  32-bit Data (LSB first)  │  Tail     │
│ 9000 + 4500 │ 32 × (560 + {560|1690})  │   560    │
│    (us)     │         (us)              │   (us)   │
└──────────────────────────────────────────────────────┘
```

- **Leader（引导码）**：mark 9000us + space 4500us，标识帧开始
- **数据位**：每位由 mark 560us + space 时长构成
    - space = 560us → 逻辑 **0**
    - space = 1690us → 逻辑 **1**
- **32 位组成**：`[address 8bit] [~address 8bit] [command 8bit] [~command 8bit]`
    - 地址/命令的反码用于错误校验

## 重复帧（Repeat Code）

持续按住遥控器按键时，发射端每隔约 108ms 发送一次重复帧：

```
mark 9000us + space 2250us + mark 560us
```

重复帧不携带新数据，仅表示"保持按住"。

## 时序图

```
        ┌────┐     ┌┐   ┌┐   ┌─┐   ┌┐
   ─────┘    └─────┘└───┘└───┘ └───┘└──────
    9000  4500 560 560 560 1690 560 560

```

## 空调协议补充

大多数空调遥控器（格力、美的等）使用 **NEC 扩展格式**：

- 引导码可能为 `mark 9000 + space 4500`（同标准 NEC），但数据长度可能为 **48 位或更多**
- 部分品牌（如格力）使用 **自定义协议**，载波频率和时序与标准 NEC 不同

本项目的 `learn` 功能可以直接学习**任何格式的原始脉冲时序**，
绕过协议解码限制——只要是红外遥控器发出的，都能精确捕获并重放。
